# My Little Capybara (Web)

เล่นเกมได้ที่: https://ruuwai.github.io/my-little-capybara-web/

Repository นี้มีเฉพาะไฟล์เกมที่ Export จาก Godot 4.7.2 สำหรับเปิดบนเว็บเบราว์เซอร์ (GitHub Pages)
ไม่มี source code ของเกม

- ใช้ได้กับเบราว์เซอร์ที่รองรับ WebGL 2.0 (Chrome, Edge, Firefox, Safari บน iOS 15 ขึ้นไป)
- เปิดครั้งแรกต้องโหลดไฟล์ประมาณ 70 MB
